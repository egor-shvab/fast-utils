# План разработки FastUtils

Разработка идёт строго по этапам, по порядку. Требования описаны в [TZ.md](TZ.md), а в этом файле — порядок работы и что считается готовым.

**Как работать с этим файлом:**
- Берём первый незавершённый этап. Следующий начинаем, только когда выполнены все пункты «Готово, когда».
- Выполненные задачи отмечаем `[x]` сразу, в том же изменении, где они сделаны.
- У текущего этапа меняем статус: ⬜ не начат → 🟡 в работе → ✅ готов.
- Если по ходу работы выяснилось, что задачу нужно разбить, перенести или добавить новую, правим этот файл. Если меняется само требование, сначала согласовываем с пользователем, потом правим TZ.md.
- Подводные камни и неочевидные решения, найденные на этапе, записываем в [CLAUDE.md](CLAUDE.md).

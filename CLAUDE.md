# CLAUDE.md — заметки для ИИ-агентов

FastUtils — фоновое приложение для macOS, которое живёт только в строке меню. Три функции по глобальным сочетаниям клавиш: OCR области экрана (⇧⌘2), перевод буфера обмена (⌥⌘T) и история буфера обмена с быстрой вставкой (⌥⌘V). Приложение пишется только для личного использования владельцем проекта.

## Документы проекта

| Файл | Что в нём | Когда обновлять |
|---|---|---|
| [TZ.md](TZ.md) | Требования: **что** делаем | Только после согласования с пользователем |
| [ROADMAP.md](ROADMAP.md) | Этапы: **в каком порядке** делаем и что считается готовым | Отмечать `[x]` и статусы этапов по ходу работы |
| CLAUDE.md (этот файл) | **Как** делаем: окружение, правила, подводные камни | Дописывать каждый раз, когда находится что-то неочевидное |

Перед началом работы прочитай ROADMAP.md, найди текущий этап (🟡 или первый ⬜) и соответствующие разделы TZ.md.

## Правила работы

- **Язык:** с пользователем и в документах (TZ, ROADMAP, CLAUDE.md) — по-русски. Код, идентификаторы, комментарии в коде и сообщения коммитов — по-английски. Строки интерфейса — только через `Localizable.strings`, основная локаль — русский.
- **Работаем по этапам ROADMAP.md.** Не перескакивай вперёд и не делай задачи будущих этапов «заодно». Закончил задачу — отметь её в ROADMAP.md в том же изменении.
- **Требования не меняем молча.** Если требование из TZ.md невыполнимо или есть вариант лучше, спроси пользователя и только потом правь TZ.md.
- **Предпочтение пользователя: простые и прямолинейные решения.** Пример: для отслеживания буфера пользователь отклонил «умный» гибрид (события ⌘C, мышь, адаптивный таймер) как костыль и выбрал простой таймер на 0,5 с. Не усложняй без явной пользы, а если усложнение кажется нужным, сначала предложи его.
- **Коммиты и пуш — только по просьбе пользователя.**
- **Подводные камни записывай сюда**, в раздел ниже, сразу как столкнулся: что случилось, почему, как обойти.

## Окружение

- Mac на Apple Silicon, macOS 27. **Xcode не установлен, и это осознанно:** пользователь не хочет засорять систему. Есть только Command Line Tools (`/Library/Developer/CommandLineTools`): Swift 6.4, SDK macOS 27. Homebrew не установлен. Не предлагай ставить Xcode или Homebrew без серьёзной причины.
- Сборка — Swift Package Manager + `scripts/build.sh`, который собирает `.app`-бандл и подписывает его. В CLT **нет** `actool`, `xcstringstool`, `ibtool`, поэтому:
  - нет Asset Catalog: иконка приложения собирается в `.icns` через `iconutil`, иконка меню — SF Symbol или PDF;
  - нет String Catalog (`.xcstrings`): используется `.lproj/Localizable.strings`;
  - нет `.xib`/`.storyboard`: весь UI в коде (SwiftUI + AppKit);
  - нет SwiftUI Previews: проверяем запуском приложения.
- Цель сборки: **только arm64**, deployment target **macOS 15**. API новее 15 используются через `if #available`.
- Bundle id: `com.yahor.FastUtils` (зафиксирован в `Resources/Info.plist`, `AppInfo.bundleIdentifier` и `scripts/build.sh`; после выдачи разрешений не менять, иначе macOS попросит их заново).
- Подпись: самоподписанный сертификат `FastUtils Dev` в login keychain, создаётся `scripts/create-signing-cert.sh` (OpenSSL → p12 → `security import -T /usr/bin/codesign`). Сертификат не помечается доверенным в системе — для `codesign` это не нужно. Если сертификата нет, `build.sh` подписывает ad-hoc и предупреждает.
- В репозитории есть `.idea/` (IDE пользователя) — он в `.gitignore`, не трогай его.

## Команды

```bash
swift build                          # быстрая проверка компиляции
swift test                           # юнит-тесты (Swift Testing)
scripts/build.sh                     # release-сборка в build/FastUtils.app
scripts/build.sh --debug             # debug-сборка с get-task-allow (можно подключить lldb)
scripts/build.sh --run               # собрать, перезапустить из build/ и стримить логи приложения
scripts/build.sh --install           # собрать, установить в /Applications и перезапустить
scripts/create-signing-cert.sh       # один раз на Mac: создать сертификат "FastUtils Dev"
swift scripts/make-icon.swift        # перегенерировать Resources/AppIcon.icns
/usr/bin/log show --last 5m --style compact --predicate 'subsystem == "com.yahor.FastUtils"'
```

Структура: `Sources/` (код), `Tests/` (тесты), `Resources/` (Info.plist, entitlements, иконка, `*.lproj`), `scripts/` (сборка), `build/` (собранный `.app`, в git не попадает).

## Архитектура (кратко, подробно — TZ.md §12)

- **Ядро (`Sources/Core`) + модули-функции (`Sources/Feature*`).** Модуль реализует протокол `Feature`, регистрируется одной строкой в `Sources/FastUtilsApp/FeatureList.swift`.
- **Модули зависят только от `Core`, но не друг от друга.** Связки (например, «распознать и перевести») делаются через `ActionRegistry` по `ActionID`. Межмодульный импорт запрещён и должен ломать сборку на уровне `Package.swift`.
- **Сервисы — через `AppContext`** (внедрение зависимостей). Синглтоны и глобальное состояние не используем, `shared`-объекты не заводим.
- **С `NSPasteboard` напрямую не работаем**, только через `PasteboardService` из Core. Иначе история начнёт путать «технические» записи приложения (перевод выделенного, вставка из истории) с копированием пользователя.
- **Панели — только через `PanelService`**, HUD — через `HUDService`, чтобы поведение было единым: позиция у курсора, Esc, клик мимо, Spaces, полноэкранные приложения.
- Настройки модуля — в его пространстве имён (`ocr.*`, `translate.*`, `clipboard.*`), секреты — только в Keychain.
- Swift 6 strict concurrency: всё, что касается UI и AppKit, помечается `@MainActor`. Тяжёлая работа (Vision, генерация превью, сеть, БД) выполняется вне главного потока.
- Логи: `os.Logger` с категорией модуля. **Содержимое буфера, распознанный и переводимый текст, ключи API в логи не пишем никогда.**

## Известные подводные камни

Заранее известные (из проработки ТЗ):

- **Подпись и разрешения (TCC).** macOS привязывает выданные разрешения («Запись экрана», «Универсальный доступ») к подписи приложения. При ad-hoc подписи (`codesign -s -`) подпись меняется с каждой сборкой, и разрешения сбрасываются. Поэтому подписываем постоянным самоподписанным сертификатом `FastUtils Dev`. Если разрешения «залипли» в странном состоянии: `tccutil reset ScreenCapture com.yahor.FastUtils` (аналогично `Accessibility`), затем выдать заново.
- **Нет события изменения буфера.** Публичного уведомления в macOS нет, поэтому опрашиваем `changeCount` раз в 0,5 с. Это решение пользователя, не меняй его без согласования (см. «Правила работы»).
- **Приватность буфера в macOS 26+.** У пользователя есть настройка доступа приложений к буферу («Вставка из других приложений»). Возможен системный запрос при чтении. Поведение на macOS 27 нужно исследовать на этапе 5 и записать сюда результат.
- **Пароли в буфере.** Менеджеры паролей помечают записи типами `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType`, `org.nspasteboard.AutoGeneratedType`, `com.agilebits.onepassword`. Такие записи в историю не попадают.
- **Снимок экрана.** `CGWindowListCreateImage` устарел начиная с macOS 15, используем `ScreenCaptureKit` (`SCScreenshotManager`). Учитывай `backingScaleFactor` и разные масштабы мониторов.
- **Apple Translation на macOS 15.** `TranslationSession` нельзя создать напрямую, она доступна только через SwiftUI-модификатор `.translationTask`, поэтому нужен SwiftUI-хост. Прямой инициализатор появился в macOS 26 — использовать через `if #available`.
- **Сочетания клавиш и раскладка.** Регистрируем по key code (Carbon, `KeyboardShortcuts`), а не по символу, иначе в русской раскладке ничего не сработает. Имитация вставки — `CGEvent` с `kVK_ANSI_V` + `.maskCommand`.
- **Secure Input.** Когда активно поле ввода пароля, имитация нажатий может не работать. Это ожидаемо: запись остаётся в буфере.
- **Конфликты сочетаний.** ⌥⌘V в Finder означает «переместить объект сюда», ⌥⌘T в некоторых приложениях занят. Пользователь знает об этом и может переназначить.
- **Агент без Dock.** `LSUIElement = YES`: у приложения нет главного меню, поэтому стандартные ⌘C/⌘V/⌘A в текстовых полях окон настроек могут не работать без явно добавленного меню «Правка» или обработки в responder chain. Проверить на этапе 1.
- **Панели и фокус.** Для окна истории нужна панель, которая принимает ввод с клавиатуры (поиск), но потом возвращает фокус предыдущему приложению перед вставкой. Запоминать `NSWorkspace.shared.frontmostApplication` **до** показа панели.

Найденные в ходе разработки (дописывать сюда: дата, этап, проблема → решение):

- **2026-11-05, этап 0 — тесты без Xcode.** XCTest в Command Line Tools нет. Используем **Swift Testing** (`import Testing`, `@Test`, `#expect`) — он работает через `swift test`. Не пиши тесты на XCTest.
- **2026-11-05, этап 0 — предупреждения линкера.** `ld: warning: search path '/Library/Developer/CommandLineTools/Developer/...' not found` появляется при каждой сборке: в CLT нет каталога Developer-фреймворков. Это безвредно, `build.sh` их фильтрует.
- **2026-11-05, этап 0 — `log` в zsh.** В zsh `log` — встроенная команда, поэтому `log show …` падает с «too many arguments». В интерактивном шелле агента вызывай **`/usr/bin/log`**. В bash-скриптах проблемы нет.
- **2026-11-05, этап 0 — уровни логов.** Сообщения `Logger.info`/`.debug` **не сохраняются** в системный журнал и видны только в живом `log stream --level debug` (так работает `build.sh --run`). То, что нужно увидеть потом через `log show`, пиши уровнем `.notice` и выше.
- **2026-11-05, этап 0 — `open` на запущенном приложении** только активирует уже запущенную копию и не перезапускает её. Перед запуском новой сборки делай `pkill -x FastUtils` (`build.sh --run/--install` делают это сами).
- **2026-11-05, этап 0 — визуальная проверка.** Агент не может сделать снимок экрана из своего шелла (`screencapture` → «could not create image from display»: у процесса агента нет разрешения на запись экрана). Чтобы проверить UI, попроси пользователя посмотреть или используй computer-use, если он доступен. Факт запуска проверяется по `pgrep -x FastUtils` и логам; признак агента без Dock — `type="UIElement"` в `lsappinfo list`.
- **2026-11-05, этап 0 — сертификат подписи.** `FastUtils Dev` создан, SHA-1 `38739094F765AA7730F3D1C43A0DF7AFC3433A1F`. `security find-identity` показывает его с `CSSMERR_TP_NOT_TRUSTED` — это нормально, подпись работает без запросов пароля. Поэтому ищем его **без** флага `-v` (с `-v` видны только доверенные). Требование подписи: `identifier "com.yahor.FastUtils" and certificate leaf = H"38739094…"` — одинаковое у всех сборок, проверка: `codesign -dr - build/FastUtils.app`. Если сертификат пересоздать, хэш изменится и все разрешения придётся выдавать заново.
- **2026-11-05, этап 0 — ресурсы SwiftPM-зависимостей.** `build.sh` копирует `*.bundle` из каталога сборки в `Contents/Resources`. Сгенерированный SwiftPM аксессор `Bundle.module` может искать бандл в корне `.app` (а туда класть файлы нельзя — сломается подпись). Проверить на этапе 2, когда появится `KeyboardShortcuts` с ресурсами.

# FastUtils

Утилита для macOS, которая живёт в строке меню и работает по глобальным сочетаниям клавиш:

| Сочетание | Что делает |
|---|---|
| ⇧⌘2 | Распознать текст в выделенной области экрана и скопировать его. Клик без перетаскивания распознаёт окно целиком. Понимает QR- и штрих-коды |
| ⌥⌘T | Перевести буфер обмена: на русский, а если текст уже русский — на английский. Переводит и выделенный текст (если включено), и картинку в буфере |
| ⌥⌘V | История буфера обмена: поиск, превью картинок, вставка по Enter |

Сочетания переназначаются в настройках, каждую функцию можно выключить. Пароли из менеджеров паролей в историю не попадают.

Требования: Mac на Apple Silicon, macOS 15 или новее. Приложение сделано для личного использования и не публикуется.

## Сборка и установка

Нужны только Command Line Tools (`xcode-select --install`). Xcode и Homebrew не нужны.

Один раз на Mac создайте сертификат для подписи. Без него разрешения «Запись экрана» и «Универсальный доступ» будут сбрасываться после каждой сборки:

```bash
scripts/create-signing-cert.sh
```

Собрать, установить в `/Applications` и запустить:

```bash
scripts/build.sh --install
```

Другие варианты:

```bash
scripts/build.sh            # release-сборка в build/FastUtils.app
scripts/build.sh --run      # собрать, запустить из build/ и показывать логи
scripts/build.sh --debug    # debug-сборка, к которой можно подключить lldb
swift build                 # только проверить компиляцию
perl -e 'alarm 300; exec @ARGV' swift test   # тесты (Swift Testing)
```

## Первый запуск

При первом запуске откроется окно с разрешениями:

- **Запись экрана** — нужна для распознавания текста.
- **Универсальный доступ** — нужен для автоматической вставки из истории и для перевода выделенного текста. Без него запись просто копируется, а вставить её можно через ⌘V.
- **Буфер обмена** — macOS 15.4+ может спросить, разрешить ли FastUtils читать буфер. Выберите «Разрешать всегда», иначе история не будет записываться.

Перевод через Apple работает без интернета, но языковые пакеты нужно скачать: Системные настройки → Основные → Язык и регион → Языки перевода. DeepL и Google подключаются в настройках перевода по своему API-ключу, ключи хранятся в связке ключей.

Иконку в строке меню можно скрыть. Тогда настройки открываются повторным запуском FastUtils из Finder или Spotlight.

## Если что-то не так

- Разрешение выдано, но не работает: `tccutil reset ScreenCapture com.yahor.FastUtils` (или `Accessibility`), перезапустить приложение и выдать разрешение заново.
- Логи: `/usr/bin/log show --last 10m --style compact --predicate 'subsystem == "com.yahor.FastUtils"'`. Содержимое буфера и распознанный текст в логи не пишутся.
- Данные истории лежат в `~/Library/Application Support/FastUtils/` (кнопка «Открыть папку с данными» в «О программе»).

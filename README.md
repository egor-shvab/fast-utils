# FastUtils

Утилита для macOS, которая живёт в строке меню и работает по глобальным сочетаниям клавиш:

| Сочетание | Что делает |
|---|---|
| ⇧⌘1 | Распознать текст в выделенной области экрана и скопировать его. Клик без перетаскивания распознаёт окно целиком. Понимает QR- и штрих-коды |
| ⌥⌘T | Перевести буфер обмена: на русский, а если текст уже русский — на английский. Переводит и выделенный текст (если включено), и картинку в буфере |
| ⌥⌘V | История буфера обмена: поиск, превью картинок, вставка по Enter |
| ⌥⌘R | Исправить раскладку: «ghbdtn» → «привет» и обратно — в выделении или в слове перед курсором |
| ⌥⌘U | Сменить регистр: ВЕРХНИЙ ↔ нижний — в выделении или в слове перед курсором |
| ⌥⌘P | Пипетка: взять цвет любого пикселя на экране и скопировать его код (`#3a7bd5`) |
| ⇧⌘2 | Скриншот с рисованием: выделить область, нарисовать на ней, скопировать или сохранить PNG |

Сочетания переназначаются в настройках, каждую функцию можно выключить. Пароли из менеджеров паролей в историю не попадают.

Требования: Mac на Apple Silicon, macOS 15 или новее. Приложение сделано для личного использования и не публикуется.

## Возможности

**Распознавание текста (⇧⌘1).** Экран «замирает», можно выделить область или кликнуть по окну — текст копируется в буфер, а уведомление показывает его начало. Пока выделяешь, у курсора видна лупа. Пробел двигает рамку, Esc или правый клик отменяют. Распознаются русский, английский и другие языки, QR- и штрих-коды. Есть действие «Распознать и перевести» (по умолчанию без сочетания).

**Перевод (⌥⌘T).** Окно с переводом появляется у курсора. Если включено, переводится выделенный текст, а буфер остаётся прежним. Если в буфере картинка, сначала распознаётся текст на ней. Языки и направление можно поменять прямо в окне. Движки: Apple (без интернета), DeepL, Google; при ошибке онлайн-движка перевод делает Apple.

**История буфера (⌥⌘V).** Окно со списком скопированного: текст, ссылки, картинки (миниатюры), файлы, образцы цветов для `#hex`/`rgb()`. Сразу можно печатать для поиска, ↑/↓ и Enter вставляют запись в приложение, где ты был, ⌘1…⌘9 — быстрый выбор, пробел — предпросмотр. Записи можно закреплять. В контекстном меню — «Перевести» и «Распознать текст». Запись истории можно приостановить из меню в строке меню.

**Раскладка и регистр (⌥⌘R, ⌥⌘U).** Работают с выделенным текстом, а если ничего не выделено — со словом перед курсором (до пробела, вместе со знаками: «kj;rf» → «ложка»). Направление раскладки определяется по тексту, после исправления раскладка системы переключается на нужную (можно выключить). Регистр: если есть строчные буквы — всё в верхний, иначе — в нижний; повторное нажатие возвращает обратно. Буфер обмена после операции остаётся прежним. В терминалах и редакторах, которые не сообщают о выделении (часть Electron- и Java-приложений), слово перед курсором не определить — выдели его.

**Пипетка (⌥⌘P).** Экран «замирает», рядом с курсором — лупа с увеличенными пикселями, под ней — образец и код цвета. Клик, Return или пробел берут цвет, Esc отменяет; стрелки двигают лупу на один пиксель, с ⇧ — на десять. Код копируется в буфер (и попадает в историю). Формат выбирается в настройках: `#3a7bd5` (по умолчанию), `#3A7BD5`, `rgb()`, `hsl()` или SwiftUI `Color`. Цвет переводится в sRGB, поэтому совпадает с кодом цвета на сайте. Нужно разрешение «Запись экрана».

**Скриншот (⇧⌘2).** Экран «замирает»: протяните рамку или кликните по окну. Дальше рисуете внутри области: кисть, стрелка, круг, прямоугольник и надпись, 7 цветов и 3 толщины, с ⇧ — квадрат, ровный круг и стрелка под 45°. Края области тянутся за ручки, «Двигать область» переносит её целиком. Готовую надпись можно править инструментами «Надпись» или «Двигать»: клик выделяет, перетаскивание двигает, угловая ручка меняет размер, двойной клик — исправить текст, ⌫ — удалить, цвет и толщина на панели перекрашивают выделенную надпись. Плавающую панель можно перетащить за ручку слева. ⌘Z / ⇧⌘Z — назад и вперёд, ⌘C — копировать, ⌘S — сохранить PNG (по умолчанию на Рабочий стол, папка меняется в настройках), Esc — закрыть. В картинку попадает только выделенная область в полном разрешении экрана, вместе с рисунками. Нужно разрешение «Запись экрана».

## Настройки

Открываются из меню в строке меню («Настройки…», ⌘,). Слева список:

- **Основные** — запуск при входе, язык интерфейса, иконка в строке меню, уведомления, сброс всех сочетаний, экспорт и импорт настроек в JSON (ключи API туда не попадают).
- **Страница каждой функции** — переключатель «Включено», её сочетания клавиш, нужные ей разрешения и собственные настройки.
- **О программе** — версия, папка с данными и краткий обзор функций с их сочетаниями.

## Сборка и установка

Нужны только Command Line Tools (`xcode-select --install`). Xcode и Homebrew не нужны.

Один раз на Mac создайте сертификат для подписи. Без него разрешения «Запись экрана» и «Универсальный доступ» будут сбрасываться после каждой сборки:

```bash
scripts/create-signing-cert.sh
```

Собрать, установить в `/Applications` и запустить:

```bash
scripts/build.sh --install
```

Другие варианты:

```bash
scripts/build.sh            # release-сборка в build/FastUtils.app
scripts/build.sh --run      # собрать, запустить из build/ и показывать логи
scripts/build.sh --debug    # debug-сборка, к которой можно подключить lldb
swift build                 # только проверить компиляцию
perl -e 'alarm 300; exec @ARGV' swift test   # тесты (Swift Testing)
```

## Релиз

1. Поднимите версию в `Resources/Info.plist`: `CFBundleShortVersionString` (например, `1.0.0`) и `CFBundleVersion` (на единицу больше прежнего).
2. Закоммитьте и соберите установщик — `build/FastUtils-<версия>.dmg` с приложением и ярлыком «Программы»:

   ```bash
   scripts/release.sh
   ```

3. Поставьте тег и отправьте его: `git tag v1.0.0 && git push origin main v1.0.0`.
4. На GitHub: **Releases → Draft a new release**, выберите тег, приложите DMG, **Publish release**.

Приложение подписано своим сертификатом, а не сертификатом Apple Developer, и не нотаризовано. На Mac, где его скачали, первый запуск блокируется: откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **«Всё равно открыть»**. На том Mac, где создан сертификат, выданные разрешения сохраняются; на другом их нужно выдать заново.

## Первый запуск

При первом запуске откроется окно с разрешениями:

- **Запись экрана** — нужна для распознавания текста.
- **Универсальный доступ** — нужен для автоматической вставки из истории и для перевода выделенного текста. Без него запись просто копируется, а вставить её можно через ⌘V.
- **Буфер обмена** — macOS 15.4+ может спросить, разрешить ли FastUtils читать буфер. Выберите «Разрешать всегда», иначе история не будет записываться.

Перевод через Apple работает без интернета, но языковые пакеты нужно скачать: Системные настройки → Основные → Язык и регион → Языки перевода. DeepL и Google подключаются по своему API-ключу — см. «Ключи для перевода» ниже.

Иконку в строке меню можно скрыть. Тогда настройки открываются повторным запуском FastUtils из Finder или Spotlight.

## Ключи для перевода

Ключ нужен только для DeepL или Google. Apple Translation работает без ключа. Вставь ключ в Настройки → Перевод → «Ключ DeepL» или «Ключ Google Cloud» и нажми «Проверить». Ключ хранится только в связке ключей: в файлы проекта и в экспорт настроек он не попадает. Если онлайн-сервис недоступен (нет интернета, неверный ключ, кончился лимит), перевод сделает Apple — об этом будет пометка в окне.

### DeepL

1. Зарегистрируйся на [deepl.com/pro-api](https://www.deepl.com/pro-api) и выбери тариф **DeepL API Free**. Банковскую карту попросят для проверки, но с бесплатного тарифа деньги не списываются.
2. Открой [Аккаунт → API Keys](https://www.deepl.com/your-account/keys) и скопируй ключ. Ключ бесплатного тарифа заканчивается на `:fx` — FastUtils по нему сам выбирает нужный адрес API.
3. Бесплатно — 500 000 символов в месяц. Сколько уже израсходовано, показывает кнопка «Проверить».

### Google Cloud Translation

1. В [Google Cloud Console](https://console.cloud.google.com/) создай проект (или выбери существующий) и привяжи платёжный аккаунт — без него API не включится.
2. Включи [Cloud Translation API](https://console.cloud.google.com/apis/library/translate.googleapis.com).
3. В разделе [APIs & Services → Credentials](https://console.cloud.google.com/apis/credentials) нажми **Create credentials → API key**. В настройках ключа в **API restrictions** выбери **Restrict key** и оставь только Cloud Translation API.
4. Бесплатно — 500 000 символов в месяц, дальше — $20 за миллион. Чтобы точно ничего не платить, в [Quotas](https://console.cloud.google.com/apis/api/translate.googleapis.com/quotas) уменьши квоту «v2 and v3 general model characters per day», например до 16 000 в день (≈ 500 000 в месяц). Когда квота кончится, Google вернёт ошибку и перевод сделает Apple.

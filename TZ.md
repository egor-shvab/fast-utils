# ТЗ: FastUtils — утилита для macOS в строке меню

> Рабочее название: **FastUtils**. Версия ТЗ: 1.1 (2026-11-05).
>
> Изменения в 1.1: только Apple Silicon; расширяемая архитектура с модулями-функциями (12); сборка без Xcode, только Command Line Tools + SwiftPM (2).

## 1. Цель и принципы

Фоновое приложение для macOS без главного окна, только с иконкой в строке меню (трее). Оно даёт три инструмента, которые вызываются глобальными сочетаниями клавиш:

1. **OCR**: выделить область экрана, распознать текст и положить его в буфер обмена.
2. **Перевод**: перевести текст из буфера обмена и показать перевод во всплывающем окне.
3. **История буфера обмена**: запоминать всё, что копируется, и по сочетанию клавиш показывать окно истории с быстрой вставкой.

**Принципы:**
- **Не мешать.** Нет иконки в Dock и окон при запуске. Всплывающие окна не забирают фокус дольше, чем нужно, и закрываются по Esc или клику мимо. В простое приложение не нагружает CPU.
- **Всё работает с клавиатуры.** Мышь нигде не обязательна.
- **Приватность.** По умолчанию все данные остаются на машине. Пароли из менеджеров паролей не сохраняются. В сеть уходит только то, что пользователь явно переводит онлайн-сервисом.
- **Каждую функцию можно отключить**, и каждое сочетание клавиш можно переназначить или снять.

## 2. Платформа и технологии

| Параметр | Значение |
|---|---|
| Минимальная ОС | macOS 15 Sequoia. Целевая и основная для тестов — macOS 27 |
| Архитектуры | **Только Apple Silicon (arm64)**. Intel не поддерживается |
| Язык | Swift 6 (strict concurrency) |
| UI | SwiftUI (настройки, содержимое панелей) + AppKit (`NSStatusItem`, `NSPanel`, оверлей выделения) |
| Распространение | Только для личного использования: сборка вне App Store, **без App Sandbox**, Hardened Runtime |
| Подпись | Постоянный самоподписанный сертификат подписи кода (создаётся один раз в «Связке ключей»). **Не ad-hoc**, иначе macOS сбрасывает выданные разрешения после каждой пересборки |
| Сборка | **Без Xcode**: Command Line Tools (уже установлены, Swift 6.4, SDK macOS 27) + Swift Package Manager. Скрипт `scripts/build.sh` собирает `.app`-бандл (Info.plist, иконка `.icns`, ресурсы), подписывает и при необходимости копирует в `/Applications`. Xcode можно поставить позже — он откроет `Package.swift` как есть |

**Ограничения сборки без Xcode** (учтены в ТЗ):
- нет `actool`: иконка приложения собирается в `.icns` через системный `iconutil`, иконка меню — PDF/SVG-ресурс или SF Symbol;
- нет `xcstringstool`: локализация через `.lproj/Localizable.strings` вместо String Catalog;
- нет SwiftUI Previews и визуального отладчика; отладка через `lldb` и логи.

**Системные фреймворки:**
- `Vision` (`VNRecognizeTextRequest` / `RecognizeTextRequest`): OCR.
- `ScreenCaptureKit` (`SCScreenshotManager`): снимок экрана. `CGWindowListCreateImage` устарел начиная с macOS 15.
- `Translation`: офлайн-перевод Apple.
- `NaturalLanguage` (`NLLanguageRecognizer`): определение языка.
- `ServiceManagement` (`SMAppService`): запуск при входе в систему.
- `Carbon` (`RegisterEventHotKey`): глобальные сочетания клавиш. Собственный модуль в `Core/Hotkeys` (см. ниже).
- `CGEvent`: имитация ⌘V для вставки.

**Сторонние зависимости** (минимум):
- ~~`KeyboardShortcuts`~~ — **не используется** (решение 2026-11-05): библиотека использует SwiftUI-макросы (`#Preview`, `@Entry`), которые без Xcode не компилируются. Сочетания клавиш — свой модуль: регистрация через Carbon, свой рекордер, проверка конфликтов.
- Хранилище истории: GRDB или SQLite напрямую — выбрать на этапе 5. SwiftData не подходит: модели `@Model` — макрос, который без Xcode не компилируется. Решающий критерий — быстрый поиск по тексту на тысячах записей.

## 3. Сочетания клавиш по умолчанию

| Действие | По умолчанию | Примечание |
|---|---|---|
| Распознать текст в области (OCR) | **⇧⌘2** | Свободно в macOS (скриншоты — ⇧⌘3/4/5/6) |
| Перевести буфер обмена | **⌥⌘T** | Выбрано вместо ⇧⌘T, чтобы не ломать «вернуть закрытую вкладку» в браузерах |
| Открыть историю буфера | **⌥⌘V** | Выбрано вместо ⇧⌘V, чтобы не ломать «вставить без форматирования». ⚠️ В Finder ⌥⌘V означает «переместить объект сюда» (после ⌘C). Если это мешает, переназначить, например, на ⌃⌥V |
| Распознать и сразу перевести | не задано | Дополнительное действие, см. 5.6 |
| Пауза записи истории | не задано | Дополнительное действие |

Требования к сочетаниям:
- Каждое переназначается в настройках через рекордер. Можно снять (оставить пустым).
- При записи сочетания показывать предупреждение, если оно:
  - уже занято другим действием FastUtils (не давать сохранить);
  - совпадает с известным системным или популярным сочетанием (⌘C, ⌘V, ⇧⌘3…6, ⌘Space, ⇧⌘T, ⇧⌘V и т. п.). Предупредить, но разрешить сохранить;
  - ~~не может быть зарегистрировано, потому что занято другим приложением~~ — технически невозможно: macOS разрешает двум приложениям зарегистрировать одно сочетание и не сообщает о конфликте (проверено 2026-11-05). Вместо этого предупреждаем о системных сочетаниях macOS и о популярных сочетаниях приложений.
- Сочетания работают в любой раскладке (привязка к key code, а не к символу).
- Если функция отключена, её сочетание снимается с регистрации и освобождается для других приложений.

## 4. Иконка в строке меню

- Монохромная template-иконка, корректная в светлой и тёмной теме.
- Во время работы (OCR, перевод) иконка кратко анимируется или меняется. Когда запись истории на паузе, иконка показывает это состояние (например, перечёркнута).
- Меню по клику:
  ```
  Распознать текст            ⇧⌘2
  Перевести буфер обмена      ⌥⌘T
  История буфера обмена       ⌥⌘V
  ─────────────
  ☐ Приостановить запись истории   ▸ (на 5 мин / 1 час / до перезапуска / пока не включу)
  ─────────────
  Настройки…                  ⌘,
  О программе
  Выйти                       ⌘Q
  ```
- В пунктах показываются текущие сочетания. Пункты отключённых функций скрыты.
- Опция «Скрыть иконку из строки меню». Тогда настройки открываются повторным запуском приложения из Finder или Spotlight.

## 5. Функция 1 — распознавание текста с экрана (OCR)

### 5.1 Сценарий
1. Пользователь нажимает ⇧⌘2.
2. Делается снимок всех экранов, и поверх каждого монитора появляется полноэкранный оверлей с **замороженным** изображением. Так можно захватить всплывающие меню и подсказки, которые исчезли бы при движении мыши. Экран затемняется, курсор становится перекрестием.
3. Пользователь тянет прямоугольник. Выделенная область показывается без затемнения, рядом видны размеры в точках.
4. После отпускания кнопки мыши оверлей мгновенно закрывается, а распознавание идёт в фоне.
5. Результат копируется в буфер обмена и попадает в историю. Появляется короткий HUD (см. раздел 8): «Скопировано: 142 символа» с первыми 1–2 строками текста.

### 5.2 Управление в режиме выделения
- **Esc** или правый клик: отмена.
- **Пробел** с зажатой кнопкой мыши: двигать уже выделенную рамку (как в нативных скриншотах).
- **Shift** при выделении: фиксировать ось (опционально).
- **Клик без перетаскивания** (опционально, этап 2): распознать окно под курсором целиком.
- Выделение работает на любом мониторе, включая разные масштабы Retina и не-Retina. Рамку можно тянуть между мониторами (если трудно реализовать, допустимо ограничиться одним монитором).
- Оверлей появляется и поверх полноэкранных приложений, на любом Space.
- Лупа рядом с курсором для точного выделения: опционально, этап 2.

### 5.3 Распознавание
- Vision, режим `.accurate`, включена языковая коррекция.
- Языки по умолчанию: русский + английский. В настройках можно выбрать список из поддерживаемых Vision языков (показывать только доступные в текущей ОС) или включить автоопределение.
- Снимок берётся в полном нативном разрешении (с учётом `backingScaleFactor`). Мелкие области перед распознаванием масштабируются в 2–3 раза, это улучшает точность.
- Пост-обработка (каждую опцию можно настроить):
  - **Порядок строк**: сверху вниз, слева направо, с учётом колонок, если Vision их различает.
  - **Режим переносов**: «как на экране» (сохранять переносы строк, по умолчанию) или «склеивать абзацы» (строки одного абзаца объединяются через пробел, перенос с дефисом в конце строки убирается).
  - Обрезка пробелов по краям, схлопывание множественных пустых строк.
- Опция «Распознавать QR- и штрих-коды»: если в области есть код, его содержимое тоже копируется (или вместо текста — настраивается).

### 5.4 Результат и ошибки
- Текст не найден: HUD «Текст не найден», буфер обмена **не изменяется**.
- Нет разрешения на запись экрана: показать окно с объяснением и кнопкой «Открыть настройки», которая ведёт в Системные настройки → Конфиденциальность → Запись экрана.
- Опция: «После распознавания показывать результат в окне» (с возможностью отредактировать и скопировать) вместо мгновенного копирования. По умолчанию выключена.
- Опция: «Звук при успешном распознавании». По умолчанию выключена.

### 5.5 Производительность
- Время от отпускания мыши до появления HUD для области ~800×400 pt — не более 1 с на Apple Silicon.

### 5.6 Распознать и перевести (дополнительное действие)
- Отдельное действие (сочетание по умолчанию не задано): после выделения области распознанный текст сразу открывается в окне перевода (раздел 6). Текст при этом тоже копируется в буфер (настраивается).

## 6. Функция 2 — перевод

### 6.1 Что переводится
По умолчанию — **текущее текстовое содержимое буфера обмена**.

Дополнительные режимы (в настройках):
- **«Если есть выделенный текст — переводить его»** (по умолчанию выключено). Приложение имитирует ⌘C в активном приложении, ждёт изменения буфера (до ~150 мс), берёт текст, а затем **восстанавливает прежнее содержимое буфера**, чтобы перевод «выделенного» не засорял буфер и историю. Если ничего не выделено, используется текущий буфер. Требует разрешения «Универсальный доступ».
- Если в буфере **изображение**: распознать на нём текст (OCR) и перевести.
- Если в буфере файлы или он пуст: HUD «В буфере обмена нет текста».

### 6.2 Выбор направления перевода
- Язык исходного текста определяется через `NLLanguageRecognizer`.
- Настройки:
  - **Основной язык перевода**: по умолчанию русский.
  - **Запасной язык перевода**: по умолчанию английский. Используется, если исходный текст уже на основном языке.
- Логика: `target = (detected == основной) ? запасной : основной`.
- Если язык определён неуверенно (короткий текст), используется значение от движка перевода (DeepL и Google сами определяют язык) или основной язык.
- В окне перевода направление можно поменять вручную (см. 6.4).

### 6.3 Движки перевода
| Движок | Как работает | По умолчанию |
|---|---|---|
| **Apple Translation** | Офлайн, бесплатно, текст не уходит в сеть. Языковые пакеты скачиваются системой один раз | ✅ основной |
| **DeepL API** | Нужен ключ (Free или Pro). Endpoint выбирается по ключу: ключи с `:fx` → `api-free.deepl.com` | опционально |
| **Google Cloud Translation API (v2)** | Нужен API-ключ | опционально |

Требования:
- В настройках выбирается основной движок. Опция «При ошибке использовать Apple Translation» (нет сети, исчерпан лимит, неверный ключ) включена по умолчанию.
- API-ключи хранятся **в Связке ключей (Keychain)**, не в UserDefaults. В настройках есть кнопка «Проверить ключ».
- Для DeepL показывать остаток лимита символов (`/v2/usage`), если это возможно.
- Apple Translation: если языковой пакет для пары не скачан, показать системный диалог загрузки (`prepareTranslation`), а не ошибку.
  - Тех. заметка: на macOS 15 сессия перевода доступна только через SwiftUI-модификатор `.translationTask`, поэтому окно перевода должно быть SwiftUI-представлением. На macOS 26+ можно создавать `TranslationSession` напрямую.
- Таймаут онлайн-запроса — 10 с, затем ошибка или фолбэк.
- Кэш последних ~50 переводов (текст + пара языков + движок), чтобы повторный вызов был мгновенным.
- Лимит длины текста: до 5 000 символов переводится сразу. Если текст длиннее, спросить «Перевести N символов?». Для онлайн-движков текст разбивается на части согласно лимитам API.

### 6.4 Окно перевода
- Плавающая панель (`NSPanel`, non-activating, поверх всех окон, на всех Spaces и поверх полноэкранных приложений). Появляется **рядом с курсором** и не выходит за границы экрана.
- Содержимое:
  - Заголовок: `English → Русский` с выпадающим выбором целевого языка и кнопкой ⇄ (поменять направление).
  - Индикатор загрузки, пока идёт перевод.
  - **Перевод**: крупно, текст можно выделять, при длинном тексте есть прокрутка. Максимальный размер окна около 500×400 pt.
  - **Оригинал**: свёрнутый блок, раскрывается по клику.
  - Кнопки: «Копировать» (⌘C), «Заменить буфер переводом», «Закрепить» (окно не закрывается при клике мимо).
  - Внизу мелко: название движка.
- Закрытие: Esc, клик вне окна (если окно не закреплено), повторное нажатие сочетания перевода.
- Авто-закрытия по таймеру нет. Перевод нужно успеть прочитать.
- Окно можно перетаскивать.
- Опция «Автоматически копировать перевод в буфер» (по умолчанию выключена).

### 6.5 Ошибки
- Понятные сообщения прямо в окне: «Нет подключения к интернету», «Неверный API-ключ DeepL», «Языковая пара не поддерживается», «Языковой пакет не загружен» + кнопка «Загрузить».

## 7. Функция 3 — история буфера обмена

### 7.1 Отслеживание
- У macOS нет публичного события «буфер изменился», поэтому счётчик `NSPasteboard.general.changeCount` опрашивается по таймеру **каждые 0,5 с**. Таймер с `tolerance` ~0,1 с, чтобы система могла объединять его пробуждения с другими. Сама проверка — чтение одного числа. Содержимое буфера читается **только** когда счётчик изменился.
- Механизм проверки изолирован в `PasteboardMonitor` за протоколом, чтобы при появлении в macOS публичного события его можно было заменить без изменений в остальном коде.
- Сохраняемые типы:
  - **Текст** (plain). Если есть RTF или HTML, они сохраняются вместе с ним, чтобы вставка шла с исходным форматированием.
  - **Изображения** (PNG, TIFF, JPEG, HEIC, а также скриншоты, скопированные через ⌃⇧⌘4).
  - **Файлы и папки** (file URLs; может быть несколько за раз).
  - **Ссылки**: текст, распознанный как URL, помечается отдельно.
  - Цвета (hex-строки) — опционально, показывать образец цвета (этап 2).
- **Не сохранять:**
  - элементы с маркерами `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType`, `org.nspasteboard.AutoGeneratedType`, `com.agilebits.onepassword` и аналогичными. Это пароли из 1Password, Bitwarden, Связки ключей и т. п.;
  - содержимое, скопированное в приложениях из **списка исключений**. Источник определяется по frontmost-приложению в момент изменения буфера. По умолчанию в списке: Связка ключей, «Пароли», 1Password, Bitwarden. Список редактируется;
  - всё, пока запись на паузе;
  - пустые строки и строки из одних пробелов.
- **Дубликаты**: если скопировано то же содержимое (сравнение по хэшу), существующая запись поднимается наверх с обновлённым временем, новая не создаётся.
- Вставка самим FastUtils не создаёт дубликат, запись просто поднимается наверх.
- Ограничения (настраиваются):
  - максимум записей: 500 по умолчанию (варианты: 100 / 200 / 500 / 1000 / 5000);
  - срок хранения: «бессрочно» по умолчанию (варианты: день / неделя / месяц / 3 месяца);
  - максимальный размер одного изображения: 20 МБ (больше — не сохранять);
  - закреплённые записи не удаляются ни по лимиту, ни по сроку.
- **macOS 26+, приватность вставки:** в новых версиях macOS у пользователя есть настройка доступа приложений к буферу (Конфиденциальность → «Вставка из других приложений»). Для FastUtils нужно разрешение «Всегда разрешать», иначе система будет спрашивать при каждом чтении. Проверить поведение на macOS 27 и учесть в онбординге.

### 7.2 Хранение
- Каталог: `~/Library/Application Support/FastUtils/`.
- Метаданные и текст лежат в SQLite (через GRDB или SQLite напрямую). Изображения хранятся отдельными файлами, плюс заранее сгенерированные превью (~200 px) для быстрого отображения.
- История сохраняется между перезапусками приложения и системы.
- Для файлов хранятся пути (не копии). Если файл удалён или перемещён, запись помечается «Файл не найден».
- В настройках: «Очистить историю» (с подтверждением; закреплённые записи — опционально) и размер занимаемого места.

### 7.3 Окно истории
- Плавающая панель, открывается по ⌥⌘V. Позиция задаётся в настройках: **у курсора мыши** (по умолчанию) / по центру активного экрана / у текстового курсора (если его координаты доступны через Accessibility; если нет — у курсора мыши).
- Открывается мгновенно: не дольше 150 мс до первого кадра. Список виртуализирован, превью грузятся лениво.
- Структура:
  - **Строка поиска сверху**, в фокусе сразу. Можно просто начать печатать — список фильтруется по тексту, названиям файлов и URL.
  - **Фильтр по типу**: Все / Текст / Изображения / Файлы / Ссылки / Закреплённые.
  - **Список записей** (сверху новые, закреплённые — отдельной секцией наверху). Каждая запись содержит:
    - иконку приложения-источника;
    - содержимое: текст — 1–3 строки с обрезкой; изображение — **превью-миниатюра** и размер в px; файл — иконка или миниатюра Quick Look, имя файла, путь серым; несколько файлов — «3 файла» + имена;
    - время относительно сейчас («2 мин назад»);
    - номер-подсказку ⌘1…⌘9 у первых девяти записей.
  - **Предпросмотр**: по пробелу (или при наведении/выборе, настраивается) показывается полный текст или полноразмерное изображение (Quick Look).
- Управление:
  | Клавиша | Действие |
  |---|---|
  | ↑ / ↓ | Перемещение по списку |
  | Enter / двойной клик / клик | **Вставить** выбранное и закрыть окно |
  | ⇧Enter | Вставить как простой текст (без форматирования) |
  | ⌘1…⌘9 | Мгновенно вставить запись с этим номером |
  | ⌘C | Только скопировать в буфер, без вставки |
  | Пробел (когда поле поиска пустое) / ⌘Y | Предпросмотр |
  | ⌘P | Закрепить / открепить |
  | ⌘⌫ | Удалить запись |
  | Esc | Закрыть (если в поиске есть текст — сначала очистить его) |
  | ⌥⌘V повторно | Закрыть |
- Контекстное меню записи: Вставить, Вставить как текст, Копировать, Закрепить, Показать в Finder (для файлов), Открыть ссылку (для URL), Распознать текст (для изображений), Перевести (для текста), Удалить.
- Клик вне окна закрывает его.

### 7.4 Механика вставки
1. При открытии окна запоминается приложение, которое было активным.
2. При выборе записи она пишется в `NSPasteboard` со всеми сохранёнными типами (для «как текст» — только plain text).
3. Окно закрывается, фокус возвращается в запомненное приложение.
4. Через ~50 мс через `CGEvent` отправляется ⌘V (key code `kVK_ANSI_V`, работает в любой раскладке).
5. Опция «Восстанавливать предыдущее содержимое буфера после вставки» (по умолчанию выключена). Если включена, через ~300 мс в буфер возвращается то, что лежало там до вставки.
6. Если нет разрешения «Универсальный доступ», запись только копируется в буфер, и показывается HUD «Скопировано — нажмите ⌘V» с подсказкой выдать разрешение.
7. Опция «Только копировать, не вставлять» (для тех, кому автовставка не нужна).

**Ограничение:** при включённом Secure Input (активно поле ввода пароля) имитация нажатий может не работать. В этом случае запись остаётся в буфере, и пользователь вставляет её сам.

## 8. Уведомления (HUD)

- Собственный лёгкий HUD без системных уведомлений и без запроса разрешения на них: небольшая плашка внизу по центру активного экрана или у курсора (настраивается), исчезает через ~1,5 с, не перехватывает клики и фокус.

## 11. Нефункциональные требования

- **Ресурсы в простое:** CPU ≈ 0 % (опрос счётчика буфера раз в 0,5 с не должен заметно нагружать систему), RAM < 80 МБ без открытых окон.
- **Скорость:** окно истории < 150 мс, оверлей OCR < 200 мс после нажатия, перевод Apple для короткого текста < 1 с.
- **Стабильность:** ошибка в одной функции не роняет приложение. Падение при обработке одного элемента буфера (например, битое изображение) логируется, и элемент пропускается.
- **Многомониторность:** все окна появляются на экране, где находится курсор.
- **Spaces и полноэкранные приложения:** панели появляются поверх полноэкранных приложений и на текущем Space (`canJoinAllSpaces`, `fullScreenAuxiliary`).
- **Темы:** светлая и тёмная, системный акцентный цвет, нативный вид (материалы / vibrancy).
- **Доступность:** VoiceOver-подписи у элементов окон, поддержка «Уменьшить движение».
- **Локализация:** русский и английский (`Localizable.strings`).
- **Логи:** `os.Logger` с категориями (ocr, translate, clipboard, hotkeys). Содержимое буфера в логи **не пишется**.

## 12. Архитектура: ядро + подключаемые модули

### 12.1 Принцип
Приложение — это **ядро** (общие сервисы) и набор **модулей-функций** (Feature). OCR, перевод и история буфера — первые три модуля. Новая функция в будущем (например, пипетка цвета, конвертер раскладки, сниппеты, сокращатель ссылок) добавляется как новый модуль **без правок ядра и других модулей**: новый SwiftPM-таргет + одна строка регистрации.

Ядро ничего не знает о конкретных функциях. Модули не знают друг о друге напрямую и общаются через **действия** (Actions) и **шину событий**.

### 12.2 Ключевые абстракции (ядро)

```swift
/// Модуль-функция. Всё, что нужно, чтобы функция появилась в приложении.
protocol Feature: AnyObject {
    static var id: FeatureID { get }            // "ocr", "translate", "clipboard"
    var title: LocalizedStringResource { get }
    var icon: String { get }                     // SF Symbol
    var requiredPermissions: Set<Permission> { get }
    var actions: [any FeatureAction] { get }     // что функция умеет делать
    var menuItems: [MenuItemDescriptor] { get }  // пункты в меню строки меню
    var settingsView: AnyView? { get }           // своя вкладка в настройках

    init(context: AppContext)
    func start() async                           // функцию включили
    func stop() async                            // функцию выключили: освободить всё
}

/// Действие — единица, на которую можно повесить сочетание клавиш,
/// пункт меню или вызвать из другого модуля.
protocol FeatureAction {
    var id: ActionID { get }                     // "ocr.captureText", "translate.clipboard"
    var title: LocalizedStringResource { get }
    var defaultShortcut: Shortcut? { get }
    func perform(_ input: ActionInput) async throws -> ActionOutput
}

/// Данные между действиями: позволяет строить цепочки (OCR → перевод).
enum ActionInput  { case none, text(String), image(CGImage), clip(ClipItem) }
enum ActionOutput { case none, text(String), image(CGImage), clip(ClipItem) }
```

**`AppContext`** — контейнер общих сервисов, который ядро передаёт каждому модулю (внедрение зависимостей, без синглтонов):

| Сервис ядра | Назначение |
|---|---|
| `HotkeyService` | Регистрирует сочетания для всех действий всех модулей, проверяет конфликты, снимает при выключении модуля |
| `ActionRegistry` | Реестр всех действий; позволяет вызвать действие другого модуля по `ActionID` (например, «Распознать и перевести» = `ocr.captureText` → `translate.show`) |
| `EventBus` | Типизированные события через `AsyncStream`: `clipboardChanged(ClipItem)`, `permissionChanged`, `settingsChanged`… Любой модуль может подписаться |
| `PasteboardService` | Единая точка чтения/записи буфера + `PasteboardMonitor` (7.1). Модули не трогают `NSPasteboard` напрямую — так история не путается с «технической» записью в буфер (перевод выделенного и т. п.) |
| `PasteService` | Вставка в активное приложение (возврат фокуса, ⌘V) |
| `ScreenCaptureService` | Снимок экранов + оверлей выделения области — пригодится будущим функциям (пипетка, скриншоты) |
| `PanelService` | Создание плавающих панелей с единым поведением (позиция у курсора, Esc, клик мимо, Spaces) |
| `HUDService` | Короткие уведомления |
| `PermissionsService` | Статусы и запрос разрешений; ядро само показывает в онбординге/настройках разрешения, которые требуют включённые модули |
| `SettingsStore` | Настройки с пространством имён на модуль (`ocr.languages`, `translate.engine`), Keychain для секретов |
| `StorageService` | Каталог данных модуля в `Application Support/FastUtils/<featureID>/` |
| `Logger` | `os.Logger` с категорией модуля |

### 12.3 Что ядро делает автоматически для каждого модуля
- добавляет переключатель «включить/выключить» и строку в онбординг (по `requiredPermissions`);
- строит пункты меню из `menuItems` и показывает текущие сочетания;
- добавляет вкладку в настройках из `settingsView`;
- регистрирует сочетания клавиш для `actions` с рекордером в общей вкладке «Сочетания клавиш»;
- вызывает `start()` / `stop()` при включении/выключении — выключенный модуль не потребляет ресурсов.

### 12.4 Расширяемость внутри модулей
- **Перевод:** движки за протоколом `TranslationEngine` — новый движок (например, локальная LLM) = новый класс + регистрация.
- **История буфера:** типы содержимого за протоколом `ClipContentHandler` (как сохранить, как показать строку в списке, как показать предпросмотр, как вставить). Новый тип (цвет, код с подсветкой) добавляется без правок окна истории.
- **OCR:** пост-обработчики текста — цепочка `TextPostProcessor` (склейка абзацев, удаление переносов, QR).
- **Действия над записью истории** (контекстное меню «Перевести», «Распознать текст») строятся из действий других модулей, принимающих соответствующий `ActionInput`. Новый модуль автоматически появится в этом меню.

### 12.5 Структура пакета

```
fast-utils/
├── Package.swift
├── TZ.md
├── scripts/
│   └── build.sh                 — сборка .app, подпись, установка
├── Resources/                   — Info.plist, AppIcon.icns, Localizable.strings
└── Sources/
    ├── FastUtilsApp/            — точка входа: создаёт AppContext, регистрирует модули
    │       FeatureList.swift    — [OCRFeature.self, TranslateFeature.self, ClipboardFeature.self]
    ├── Core/                    — протоколы Feature/Action, AppContext, все сервисы ядра,
    │                              меню, настройки, онбординг, общие UI-компоненты
    ├── FeatureOCR/
    ├── FeatureTranslate/
    └── FeatureClipboard/
Tests/
    ├── CoreTests/
    └── Feature*Tests/            — логика модулей тестируется без UI через моки сервисов ядра
```

Модули зависят **только от `Core`**, но не друг от друга (это проверяется компилятором через зависимости таргетов в `Package.swift`).
